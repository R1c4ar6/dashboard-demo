# Dashboard Demo

This project is a demo dashboard application built with Next.js. It showcases a modern web dashboard interface, including data visualization, user management, and interactive components. The app is designed to demonstrate best practices in React development, using TypeScript for type safety and Tailwind CSS for styling.

## Features

- Responsive dashboard layout
- Data charts and graphs
- User authentication simulation
- Real-time data updates
- Modular component architecture

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Chart.js (or similar for visualizations)
- DummyJSON (for backend data simulation and authentication)
